# 题目检索

一个纯前端的关键词检索题库。把题目和答案录进 `questions.md`，搜索关键词即可过滤出包含它的题目和答案。

## 文件说明

- `index.html` 页面
- `style.css` 样式
- `script.js` 逻辑（拉取题库、解析、搜索、高亮）
- `questions.md` 题库 —— **你平时只改这一个文件**
- `check.js` 查重脚本（录完题跑一下，检测重复题）
- `README.md` 本文

## 怎么录题

打开 `questions.md`，按下面格式追加：

```
### 题干（这道题的问题）

**答案**

答案正文，可以多行，也可以用代码块、列表、表格。
```

规则：

- 每道题以 `### ` 开头，后面直接写题目。
- `**答案**` 单独一行，下面是答案正文。
- 题目和答案之间、题与题之间会自动分隔，答案里可以随便放代码块 / 列表 / 表格。

## 查重

录完一批题后，在项目目录下运行：

```
node check.js
```

它会检测**完全重复**的题目（忽略大小写、空格、标点），有重复就列出在第几行，方便你去删。无重复时输出 `✅ 无重复`。

## 本地预览

在项目目录下运行：

```
python3 -m http.server
```

然后浏览器打开 http://localhost:8000 即可。

> 不要直接双击 `index.html`，浏览器会拦截 `fetch` 读取本地文件。

## 部署到 GitHub Pages

1. 新建一个 GitHub 仓库，把这几个文件推上去。
2. 仓库 Settings → Pages → Source 选分支（main）→ 保存。
3. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`。
